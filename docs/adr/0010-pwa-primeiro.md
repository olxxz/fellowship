# 0010. PWA primeiro, Expo depois

- **Status:** Aceita
- **Data:** 2026-11-25

## Contexto

O modo presencial usa o celular para ficha, dados e notas. Um app nativo agora atrasaria o MVP.

## Decisão

O celular usa a web como PWA. Um app com Expo pode vir depois, reaproveitando `@fellowship/core`.

## Consequências

- Alvos de toque de 44px e layout de celular desde a fase 0.
