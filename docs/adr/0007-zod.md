# 0007. Zod para validação

- **Status:** Aceita
- **Data:** 2026-11-25

## Contexto

Templates de ficha, formulários e a API precisam validar os mesmos formatos.

## Decisão

Zod como fonte única dos schemas. Os tipos TypeScript são inferidos dos schemas.

## Consequências

- Os schemas de domínio ficam em `@fellowship/core`, compartilhados entre front e back.
