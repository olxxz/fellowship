# 0001. Registrar decisões em ADRs

- **Status:** Aceita
- **Data:** 2026-11-25

## Contexto

O projeto começa com um grupo pequeno, mas a especificação já lista várias escolhas de stack. Sem registro, o motivo de cada escolha se perde, e decisões são rediscutidas.

## Decisão

Cada decisão de arquitetura vira uma ADR curta em `docs/adr`, no formato contexto, decisão e consequências. A tabela "Stack e decisões técnicas" da especificação deu origem às ADRs 0002 a 0012.

## Consequências

- Mudar uma decisão exige uma nova ADR que substitui a anterior.
- Decisões em aberto ficam listadas como pendentes no índice até virarem ADR.
